03 · Claude Code 安裝與試用

安裝指令說明：PATH 通訊錄

第 2、3 步：PATH 是電腦找程式的通訊錄

你打 claude，終端機就照 PATH 這本通訊錄，一個一個資料夾找 claude.exe。安裝程式把它放在 %USERPROFILE%\.local\bin，但有時沒把這個資料夾寫進通訊錄，所以我們自己寫。

步驟與片段意思
第 2 步：GetEnvironmentVariable('Path','User')讀出你帳號的通訊錄。
第 2 步：-notlike "*\.local\bin*"檢查裡面還沒有這個資料夾。
第 2 步：SetEnvironmentVariable(…,'User')沒有才加上去存回。只改你自己的帳號，不需要管理員。
第 3 步：$env:Path += …終端機只在打開時抄一份通訊錄。這行直接改「現在手上這份」，所以不用關掉重開就能用。

類型：A 把網域指到一個 IP 位址（伺服器的門牌號碼）。
類型：CNAME 把網域指到另一個網域，例如 你的帳號.github.io。
類型：TXT 一段文字，用來證明「這個網域是我的」，不影響網站能不能打開。
Host：@ 網域本身，例如 example.com（不加 www）。
Host：www 子網域，例如 www.example.com。
Value 要指去的地方：IP 位址或另一個網域。
TTL 改了設定後，多久會更新到全世界。用 Automatic 就好。

所以 @ 和 www 要各設一次，兩種網址才都打得開。
