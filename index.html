02 · VS Code 安裝與介紹

下載 VS Code

  1. 打開瀏覽器，到 code.visualstudio.com。
  2. 按藍色的下載按鈕。網站會自動選好你的系統。
  3. 到「下載」資料夾，雙擊剛下載的安裝檔。

檔名像 VSCodeUserSetup-x64-….exe。這是 User Installer，不用管理員權限。

下載的是 .zip。解開後，把 Visual Studio Code 拖進「應用程式」資料夾。

只從官網下載。搜尋結果裡的其他下載站可能夾帶廣告軟體。

02 · VS Code 安裝與介紹

安裝時要勾的選項

一路按「下一步」。到「選取其他工作」這頁，確認下面都有勾：

  1. 將「以 Code 開啟」動作加入 Windows 檔案總管檔案的操作功能表。
  2. 將「以 Code 開啟」動作加入 Windows 檔案總管目錄的操作功能表。
  3. 加入 PATH（重新啟動後生效）。這個最重要，預設已經勾好。

前兩個讓你在資料夾上按右鍵，就能用 VS Code 打開。最後勾「啟動 Visual Studio Code」，按完成。

02 · VS Code 安裝與介紹

第一次打開：換成中文

右下角通常會跳出「安裝語言套件」的提示，直接按安裝並重新啟動。沒看到的話：

  1. 按 Ctrl+Shift+X 打開延伸模組（Extensions）。
  2. 搜尋 Chinese (Traditional)，安裝 Microsoft 出的那一個。
  3. 按右下角的 Change Language and Restart。

裝好了畫面還是英文，就手動指定顯示語言：

  1. 按 Ctrl+Shift+P 打開命令選擇區，輸入 display。
  2. 選 Configure Display Language（設定顯示語言）。
  3. 選「中文(繁體) zh-tw」，再按 Restart 重新啟動。

歡迎頁可以直接關掉。想換深色或淺色外觀：Ctrl+K 放開，再按 Ctrl+T。

02 · VS Code 安裝與介紹

打開一個資料夾

VS Code 一次打開「一整個資料夾」。一個網站就是一個資料夾。

  1. 上方選單選「檔案 → 開啟資料夾」。
  2. 先選「文件」資料夾試試看，按「選擇資料夾」。
  3. 問「是否信任此資料夾中檔案的作者」：自己的資料夾就按「是，我信任作者」。

從別人那裡下載、不確定的資料夾，先選「否，我不信任」，只看不執行。

VS Code 畫面的五個區塊

1
2 側邊欄
3 編輯區
4 面板（終端機）

02 · VS Code 安裝與介紹

在 VS Code 打開終端機

終端機（terminal）是用打字下指令的視窗。VS Code 下方的面板就有一個，Windows 預設是 PowerShell。

  1. 按 Ctrl+`（Esc 下面那顆鍵），或從上方選單選「終端機 → 新增終端」。
  2. 畫面下方會出現終端機面板。
  3. 看到下面這行，就可以輸入指令。
PS C:\Users\你的名字>

這行提示像地址牌：告訴你現在在哪個資料夾。PS 表示這裡是 PowerShell。

之後投影片寫「在 PowerShell 輸入」，就是貼在這個終端機裡。

03 · Claude Code 安裝與試用

安裝 Claude Code

在 VS Code 的終端機（PowerShell）貼上 Windows PowerShell 這一格。

irm https://claude.ai/install.ps1 | iex
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
curl -fsSL https://claude.ai/install.sh | bash

需要 Claude Pro / Max 訂閱或 Console 帳號（API 預付費）；Team / Enterprise 也可。 免費 claude.ai 帳號不含 Claude Code。

Windows 10 1809 以上或 Windows 11、至少 4GB 記憶體與網路。 不用管理員權限，也不用先裝 Git，等一下的 Git 第一章才裝。原生安裝會自動更新。

這裡大概要等 5 到 10 分鐘。下載時畫面不會動、也沒有進度條，下載完才會出現下面的文字。不要關掉視窗。 

Setting up Claude Code...

Installing Claude Code native build latest...

出現這兩行代表正在安裝，再等它跑完。完成後把 VS Code 整個關掉重開。

看到「The token '&&' is not a valid statement separator」：把 CMD 指令貼進 PowerShell 了。 看到「'irm' is not recognized」：把 PowerShell 指令貼進 CMD 了。

03 · Claude Code 安裝與試用

剛剛那行指令在做什麼

下載安裝程式，然後直接執行它。

片段 意思
irm Invoke-RestMethod 的縮寫。到網址把內容抓下來，這裡抓到的是一段 PowerShell 程式碼。
https://claude.ai/install.ps1 要抓的網址。.ps1 是 PowerShell 腳本的副檔名。
| 管線（pipe）：把左邊的結果交給右邊。
iex Invoke-Expression 的縮寫。把收到的文字當成程式碼執行。

腳本會下載 Claude Code，放到 %USERPROFILE%\.local\bin，並加進 PATH（電腦找程式的路線清單）。 所以裝完要重開 VS Code，才找得到 claude。

irm … | iex 會直接執行網路上的程式碼。只用在信任的官方網址；來路不明的網站叫你貼這種指令，不要照做。

03 · Claude Code 安裝與試用

卡關：無法辨識 claude

claude : 無法辨識 'claude' 詞彙是否為 Cmdlet、函數、指令檔或可執行程式的名稱。

電腦找不到 claude 這個程式。依序試：

  1. VS Code 所有視窗都關掉，再重新打開，開新的終端機再打 claude。
  2. 還是不行，先確認程式有沒有裝好。顯示 True 是有裝好，False 代表安裝沒跑完，回上一張重裝。
Test-Path $HOME\.local\bin\claude.exe

有裝好但找不到，就把它的位置加進 PATH：

[Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path', 'User') + ";$HOME\.local\bin", 'User')

再把 VS Code 整個關掉重開。等不及的話，這行可以先在目前的終端機啟動：

& "$HOME\.local\bin\claude.exe"

03 · Claude Code 安裝與試用

設定 2：底下的狀態列

狀態列（status line）像儀表板。在底下顯示目前模型、資料夾、Git 分支。

在 Claude Code 裡貼上，讓它幫你設定：

03 · Claude Code 安裝與試用

設定 3：權限模式與安全

Shift+Tab 切模式。先看底下的名稱，練習時切到 manual mode。

manual / default（預設）

⏸ manual mode on：改檔、跑指令前先問你。新手先用這個。

accept edits（接受編輯）

⏵⏵ accept edits on：改檔與簡單檔案指令不再逐次問。

plan（計畫）

⏸ plan mode on：只看、只規劃，不修改。

auto（自動）

⏵⏵ auto mode on：另一個模型代你檢查動作。新版可能從這個模式開始。

/permissions

在 Claude Code 裡查看允許、詢問與拒絕的規則。

看清楚授權提示再按一般的 Yes。先不要選「Yes, and don’t ask again」。 不懂就問它「這個指令會做什麼？」平常電腦不要用略過權限（bypassPermissions）。

Esc 中斷；空白輸入列連按兩次 Esc 可回到之前（rewind）。 這能復原 Claude 的檔案編輯，但不能復原指令搬動、刪除的檔案，也不能代替 Git。

04 · 網站前端與後端

前端與後端：想成一間餐廳

前端（frontend）＝店面

客人看得到的菜單、裝潢與按鈕。HTML 是菜單內容和架構；CSS 管裝潢與配色； JavaScript（JS）讓按鈕有反應。

後端（backend）＝廚房＋倉庫

客人看不到。處理訂單、記住預約，把資料收進資料庫（database）。

04 · 網站前端與後端

靜態網站與動態網站

靜態網站（static website）

像印好的作品冊：照片、介紹、價目表先準備好，打開就看得到。按鈕和照片切換也能有。

動態網站（dynamic website）

像預約櫃台：依客人和時間查資料，記住誰約了哪個時段。

你的網站現在：靜態網站就夠了。作品、服務、價目表，加一個 LINE 預約連結。

04 · 網站前端與後端

SEO 先打底：讓 Google 找得到你

搜尋引擎最佳化（SEO），先想成替店面掛好招牌。

  1. 每頁寫清楚標題與描述：這是誰的店、提供什麼服務。
  2. 作品照片加說明文字（alt），例如「台中霧眉：自然眉型前後對比」。
  3. 文字自然放入地區關鍵字，例如「台中霧眉」。
  4. 建立 Google 商家，填好地點、營業時間與聯絡方式。

靜態網站最容易做好 SEO 的基本功。之後可以請 Claude Code 幫忙檢查；搜尋排名仍需要時間。

整個流程一張圖

Lovable→ GitHub（雲端）→ 你的電腦（clone）→ Claude Code 修改→ commit→ push→ GitHub → Lovable 自動同步回去

複製到本機叫 clone；把存檔送上雲端叫 push。今天把你的網站接起來。

07 · Git 第三章：實戰

方法 A（推薦）：Lovable 連上 GitHub

  1. 打開 Lovable 專案設定（Project settings）→ Git → GitHub。
  2. 按 Add account，安裝 Lovable 的 GitHub App。
  3. 按 Connect。Lovable 會建立新的私人儲存庫（repository，簡稱 repo）。
  4. 開始雙向同步，預設同步 main 分支。推上這個分支，Lovable 也會收到。

推薦用於持續修改網站，讓本機與 Lovable 保持雙向同步。

不要刪掉 GitHub 上的 repo，會斷開同步。一次只會同步一個分支，預設 main。

07 · Git 第三章：實戰

方法 B：下載程式碼再上傳

  1. Lovable 專案設定 → Git → Download codebase。你的付費方案可以直接下載。
  2. 解壓縮。打開 PowerShell，走到解壓縮後的資料夾。
cd "C:\Users\你的名字\Downloads\你的網站資料夾"
git init
git add .
git commit -m "從 Lovable 匯入"
gh repo create my-site --private --source=. --remote=origin --push

這樣建立的 repo 不會跟 Lovable 同步，適合備份或一次性使用；持續修改請用方法 A。 後面有「自動同步」的步驟只適用方法 A。

07 · Git 第三章：實戰

額外：SSH key 是什麼

額外項目，有時間再做。gh 登入後已經能 clone 和 push，不做也沒關係。

SSH 是安全連線的方式。SSH 金鑰（key）像鑰匙與門鎖：

私鑰 id_ed25519

鑰匙留在自己電腦，絕不給別人。

公鑰 id_ed25519.pub

交給 GitHub 當門鎖。設好後，push 不用再輸入 GitHub 帳密。

懶人做法：下面指令會引導你自動產生、上傳金鑰。我們接著練手動步驟，知道鑰匙放哪裡。 

gh auth login -p ssh

07 · Git 第三章：實戰

額外：產生 SSH key

Windows 10 1809 以上與 Windows 11 已內建 OpenSSH 用戶端。把信箱換成自己的：

ssh-keygen -t ed25519 -C "你的 GitHub 信箱"
  1. 存放位置用預設，按 Enter。若已有同名金鑰，不要覆蓋，先請老師協助。
  2. 密碼可留空，按 Enter 兩次；想多一層保護也可設密碼。
  3. 檔案會放在 C:\Users\你的名字\.ssh\。
ls $HOME\.ssh

07 · Git 第三章：實戰

額外：把公鑰交給 GitHub

第一次要多給 gh 一個權限，允許它上傳公鑰。

gh auth refresh -h github.com -s admin:public_key
gh ssh-key add $HOME\.ssh\id_ed25519.pub --title "我的筆電"

也可以改用網頁：先複製公鑰。

Get-Content $HOME\.ssh\id_ed25519.pub | Set-Clipboard

GitHub Settings → SSH and GPG keys → New SSH key → 貼上。兩種做法擇一即可。

07 · Git 第三章：實戰

額外：測試 SSH 連線

ssh -T git@github.com

第一次看到 Are you sure you want to continue connecting (yes/no)?，輸入：

yes
Hi 你的帳號! You've successfully authenticated, but GitHub does not provide shell access.

看到這行就成功。它說不提供 shell 是正常的。讓 gh 之後使用 SSH：

gh config set git_protocol ssh

已經抓下來的網站，在那個專案資料夾改用 SSH 連線地址：

git remote set-url origin git@github.com:你的帳號/你的repo.git
git remote -v
